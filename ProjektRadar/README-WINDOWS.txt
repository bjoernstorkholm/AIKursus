PROJEKTRADAR - WINDOWS / .NET 10
================================

ProjektRadar har nu to modes:
  - Projektkontrol
  - Arkitekturoverblik

Anbefalet placering:
  C:\ProjektRadar\ProjektRadar

Sådan gør du:
1. Opret mappen C:\ProjektRadar
2. Udpak den leverede ZIP direkte i C:\ProjektRadar
3. Resultatet skal være:
   C:\ProjektRadar\ProjektRadar\ProjektRadar.csproj
4. Åbn PowerShell og kør:
   cd C:\ProjektRadar\ProjektRadar
   dotnet restore
   dotnet run
5. Åbn den adresse, som dotnet run viser.

Krav:
- .NET 10 SDK
- Moderne browser (Edge/Chrome anbefales)

Mode-switch:
Dropdownen "Visning" ligger i topbaren til venstre for hovedmenuen.

Demofiler:
- Projektkontrol: Projekt Aurora-demofiler
- Arkitekturoverblik: 16 rodede arkitekt-/specifikationsfiler

Denne version bruger Demoanalyse. Ingen dokumentdata sendes til OpenAI API.

Bemærk:
ChatGPT-miljøet kan ikke ændre eller skrive direkte til din lokale Windows-mappe. ZIP-filen skal derfor udpakkes lokalt af dig.
